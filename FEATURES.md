## 🛠️ Composables Vue

### 1. **useAdvancedFilters**
```javascript
const {
  filters,
  isFiltering,
  hasActiveFilters,
  activeFiltersCount,
  applyFilters,
  clearFilters,
  setFilter,
  toggleFilter
} = useAdvancedFilters(routeName, options);
```

**Features:**
- Debounce
- localStorage persistence
- Multi-filters support
- Array/Boolean/String filters

### 2. **useDarkMode**
```javascript
const {
  isDark,
  mode,
  enableDark,
  enableLight,
  enableAuto,
  toggle
} = useDarkMode();
```

**Features:**
- 3 modes (light, dark, auto)
- System preference detection
- localStorage persistence
- Meta theme-color update

### 3. **useDataExport**
```javascript
const {
  downloadCSV,
  downloadExcel,
  downloadJSON,
  copyToClipboard,
  exportData,
  printData
} = useDataExport();
```

**Features:**
- Multiple formats
- UTF-8 encoding
- BOM for Excel compatibility
- Clipboard API

### 4. **useChartExport**
```javascript
const {
  exportChartAsPNG,
  exportChartAsJPEG,
  printChart,
  copyChartToClipboard,
  downloadPDFReport
} = useChartExport();
```

**Features:**
- Canvas toDataURL
- High quality export
- Print support
- Multiple formats

### 5. **useKeyboardShortcuts**
```javascript
const {
  registerShortcut,
  unregisterShortcut,
  getAllShortcuts
} = useKeyboardShortcuts();
```

**Features:**
- Global shortcuts
- Form fields ignore
- Modifiers (Ctrl, Alt, Shift, Meta)
- Help modal

### 6. **useComptaProShortcuts**
```javascript
const {
  showHelp,
  toggleHelp,
  getAllShortcuts
} = useComptaProShortcuts();
```

**Features:**
- Pre-configured shortcuts
- Navigation shortcuts
- Action shortcuts
- Help system
